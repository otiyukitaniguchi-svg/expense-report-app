# Google Maps API キーの設定手順

交通費詳細の「候補を検索」(地名・住所検索)と「距離を計算」(経路距離)は、Google Maps Platform を使います。

- 地名・住所検索: **Places API (New)** の Text Search
- 距離計算: **Routes API**(車・徒歩・公共交通機関。車は「有料道路を使わない」に対応)

API キーはサーバー側(`api/geocode.ts`, `api/calculate-distance.ts`)だけで使います。ブラウザには送られません。

## 1. Google Cloud プロジェクトを作る

1. https://console.cloud.google.com/ に Google アカウントでログインする
2. 画面上部のプロジェクト選択 →「新しいプロジェクト」→ 名前(例: `expense-report-app`)を入れて作成
3. 作ったプロジェクトが選択されていることを確認する

## 2. お支払い情報(請求先アカウント)を登録する

Google Maps Platform は、無料枠内の利用でも請求先アカウントの登録が必要です。

1. 左メニュー「お支払い」→ 請求先アカウントを作成し、クレジットカードを登録する
2. このプロジェクトをその請求先アカウントにリンクする

## 3. API を有効にする

左メニュー「API とサービス」→「ライブラリ」で、次の 2 つを検索して「有効にする」を押す。

- **Places API (New)**(「Places API」の旧版ではなく、(New) が付いている方)
- **Routes API**

## 4. API キーを作成して制限をかける

1. 「API とサービス」→「認証情報」→「認証情報を作成」→「API キー」
2. 作成されたキーの「キーを編集」を開く
3. **API の制限** →「キーを制限」を選び、`Places API (New)` と `Routes API` の 2 つだけにチェック → 保存
   - 「アプリケーションの制限」は「なし」のままにする(Vercel のサーバーから呼ぶため、ウェブサイト制限や IP 制限は使えない)
4. キーの値をコピーする(**チャットやメールには貼らないこと**)

## 5. 予算アラートを設定する(推奨)

想定外の請求を防ぐため、通知を設定しておく。

1. 「お支払い」→「予算とアラート」→「予算を作成」
2. 対象プロジェクトを選び、金額(例: 1,000 円)を設定する
3. しきい値(50% / 90% / 100%)でメール通知されるようにする

あわせて、「API とサービス」→ 各 API →「割り当て」で 1 日あたりのリクエスト上限を下げておくと、さらに安心です(例: 各 500 回/日)。

## 6. Vercel に登録する

1. https://vercel.com/ → `expense-report-app` プロジェクト → **Settings → Environment Variables**
2. Key: `GOOGLE_MAPS_API_KEY`、Value: コピーしたキー
3. Environments は **Production / Preview / Development** すべてにチェック → Save
4. **Deployments** タブで最新のデプロイの「…」→ **Redeploy** を押す(環境変数は再デプロイしないと反映されない)

`VITE_` を付けた名前にはしないでください。`VITE_` が付くとブラウザ側にキーが漏れます。

## 料金の目安

各 API には毎月の無料利用枠があり、5〜20 人の社内利用(1 件の登録で検索 2 回 + 距離計算 1 回)であれば、通常は無料枠内に収まります。最新の料金と無料枠は次のページで確認してください。

- https://mapsplatform.google.com/pricing/
- https://developers.google.com/maps/billing-and-pricing/pricing

## 動作確認

再デプロイ後、アプリにログインして「交通費詳細を追加」を開き、次を確認する。

1. 番地まで含めた住所(例: `那覇市泉崎1-2-2`)と施設名(例: `沖縄県庁`)の両方で候補が出る
2. 候補を選んで「距離を計算」を押すと距離が入る
3. 「有料道路を使わない」のオン/オフで、高速を使う区間の距離が変わる

エラー表示の意味:

| 表示 | 原因 |
|---|---|
| `GOOGLE_MAPS_API_KEY を設定してください` | Vercel に未登録、または登録後に再デプロイしていない |
| `APIキーと利用制限を確認してください` | API が有効になっていない、キーの API 制限に該当 API が入っていない、お支払い未登録 |
| `利用上限に達しました` | 割り当て(1 日の上限)に達した |

詳細なエラー内容は Vercel の **Logs** で `[Google Places]` / `[Google Routes]` を検索すると確認できます。
